Ticket QR code

This code opens the live home tour page. Because the page itself updates, you only print this code once, even if homes change on tour day.

  • Print it at least 1 inch (2.5 cm) square. 1.25 inches is safer for older phones.
  • Keep dark ink on a light background with a quiet margin around it.
  • Scan the printed proof with an iPhone and an Android phone before the full run.
